# 计算所选系统的理论性能，包括flop峰值、内存带宽、机器平衡

## 示例1

以单节点双路 Intel Xeon Platinum 8480+ 为例

| 指标              | 计算方法               | 值                                                    |
| --------------- | ------------------ | ------------------------------------------------------ |
| FP64 FLOP峰值 | 核心数 × 每周期FLOP × 主频 | 2×56核 × 2(FMA)×2(AVX-512) × 2.0 GHz ≈ 3.58 TFLOP/s |
| 内存带宽        | 通道数 × 速率 × 64bit/8 | 16通道 × 4800 MT/s × 8 B ≈ 614 GB/s                  |
| 机器平衡        | 带宽 / FLOP峰值        | 614 / 3580 ≈ 0.17 Byte/FLOP                        |

### 关键参数
| 项目             | P-core (Raptor Cove)                | E-core (Gracemont) |
| -------------- | ----------------------------------- | ------------------ |
| 数量             | 8                                   | 12                 |
| 最大睿频           | 5.6 GHz (TB Max 3.0) / 5.5 GHz (全核) | 4.3 GHz            |
| 基础频率           | 3.4 GHz                             | 2.5 GHz            |
| 256-bit FMA 吞吐 | **2 条/周期**                          | **1 条/周期**         |
| 超线程            | 支持 (16 线程)                          | 不支持 (12 线程)        |

### flop峰值
| 精度            | 每核每周期 FLOP   | 计算公式                 | 峰值                              |
| ------------- | ------------ | -------------------- | ------------------------------- |
| **SP (FP32)** | P: 32, E: 16 | 8×5.6×32 + 12×4.3×16 | **2259.2 GFLOPS ≈ 2.26 TFLOPS** |
| **DP (FP64)** | P: 16, E: 8  | 8×5.6×16 + 12×4.3×8  | **1129.6 GFLOPS ≈ 1.13 TFLOPS** |

这是基于 Intel 标称 Max Turbo Frequency 的理论峰值。实际持续运行时，由于功耗/温度限制（PL1=125W, PL2=253W），AVX2 重载下全核频率会低于标称睿频。若按基础频率估算，持续峰值约为 SP 1.35 TFLOPS / DP 0.68 TFLOPS
