# 将程序“像素风格”，用openMP进行加速
# 输入图片，程序将其转化为像素风格图片输出，比较耗时

## 文件说明

| 文件 | 说明 |
|---|---|
| `pixel_art_serial.cpp` | 串行版本（单线程） |
| `pixel_art_omp.cpp` | OpenMP 并行版本，与串行版逐行对应 |

两个版本算法完全相同，唯一区别是 OpenMP 版在外层循环上加了一条并行指令。

## 编译与运行

```bash
make            # 编译三个程序
make test       # 生成测试图并分别用串行/并行版处理

# 或手动：
g++ -O2 -Wall                     -o pixel_art_serial pixel_art_serial.cpp
g++ -O2 -Wall -fopenmp            -o pixel_art_omp    pixel_art_omp.cpp

./pixel_art_serial 输入.png 输出_serial.png 8
./pixel_art_omp    输入.png 输出_omp.png    8
```

## 实验结果

| 配置 | block=8 | block=2 |
|---|---|---|
| 串行版 | 1.5 ms | 3.3 ms |
| OpenMP 4 线程 | 0.9 ms | 1.2 ms |
