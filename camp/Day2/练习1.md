# 判断代码段是否适用openMP加速

## 示例1
```cpp
double pi_serial_loop() {
  long long n = 500000000;
  double step = 1.0 / (double)n;
  double pi_serial;
  double sum_serial = 0.0;
  for (long long i = 0; i < n; i++) {
    double x = (i + 0.5) * step;
    sum_serial += 4.0 / (1.0 + x * x);
  }
  pi_serial = sum_serial * step;
  return pi_serial;
}
```
适合使用openMP加速
### 原因： 纯计算密集型的数值积分，且无带宽依赖。

openMP版本测试：
源代码：HighPerformanceComputing/tools/cpu/pi_loop.cpp
编译执行 g++ -fopenmp -O2 -o small_loop tools/cpu/small_loop.cpp && ./small_loop
Output：普通耗时：0.000000109，错误加速耗时：0.016514965



## 示例2
```cpp
double small_serial_loop() {
  double sum = 0.0;
  int n = 100;
  for (int i = 0; i < n; i++) {
    sum += i * 0.5;
  }
  return sum;
}
```
不适用openMP加速
### 原因：当循环体非常简单，创建线程和同步的开销会超过并行计算带来的收益。

openMP版本测试：
源代码：HighPerformanceComputing/tools/cpu/small_loop.cpp
编译执行 g++ -fopenmp -O2 -o pi_loop tools/cpu/pi_loop.cpp && ./pi_loop
Output：
[串行] π ≈ 3.141592653589814, 耗时: 0.380 秒
[并行] π ≈ 3.141592653589782, 耗时: 0.073 秒
理论值:  3.141592653589793
加速比:  5.23 x (使用 28 线程)
