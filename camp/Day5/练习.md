# 药物分子生成模型推理加速

使用在 MOSES 数据集，手搓模型

在https://github.com/molecularsets/moses/tree/master/data下载数据train.csv、test.csv，保存到tools/llm/data文件及下

# 文件说明

tools/llm文件夹下

| 文件 | 说明 |
| --- | --- |
| `molecular_gpt.py` | 原始文件 |
| `molecular_gpt_cuDNN.py` | cuDNN 加速 |
| `molecular_gpt_KVCache.py` | 手写 KV Cache 加速 |
| `checkpoints` | 模型权重 |
| `data` | 数据 |

## 安装依赖
```bash
pip install -r requirements.txt
```

### 单个生成
```bash
python molecular_gpt_s.py --mode generate --model_path ./checkpoints/best_mode
l.pt --start_fragment "c1cc" --max_new_tokens 100 --temperature 1.0

python molecular_gpt_cuDNN_s.py --mode generate --model_path ./checkpoints/best_model.pt --start_fragment "c1cc" --max_new_tokens 100 --temperature 1.0

python molecular_gpt_KVCache_s.py --mode generate --model_path ./checkpoints/best_model.pt --start_fragment "c1cc" --max_new_tokens 100 --temperature 1.0
```

### 批量生成
```bash
python molecular_gpt.py --mode generate --model_path ./checkpoints/best_mode
l.pt --start_fragment "c1cc" --max_new_tokens 100 --temperature 1.0

python molecular_gpt_cuDNN.py --mode generate --model_path ./checkpoints/best_model.pt --start_fragment "c1cc" --max_new_tokens 100 --temperature 1.0

python molecular_gpt_KVCache.py --mode generate --model_path ./checkpoints/best_model.pt --start_fragment "c1cc" --max_new_tokens 100 --temperature 1.0
```


### 训练
```bash
python molecular_gpt.py --mode train --data_dir ./data --epochs 20 --batch_size 64 --use_amp
```
