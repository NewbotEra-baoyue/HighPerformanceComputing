# DrugLLM: 手搓 Transformer 的 MOSES 药物分子生成

从零实现的 Decoder-only Transformer(GPT 风格),在 MOSES 数据集(~160 万药物分子 SMILES)上训练字符级语言模型,用于分子生成。

## 安装

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 准备数据与词表(自动下载 MOSES CSV)

```bash
python data.py
```

## 训练

CPU 快速跑通版(小模型、20 万条数据、分钟级):

```bash
python train.py --config cpu_quick --device cpu
```

GPU 完整训练版(RTX 4070,全量 160 万数据):

```bash
python train.py --config gpu_full --device cuda
```

断点续训:`python train.py --config gpu_full --resume`。checkpoint 存于 `ckpt/`(`best.pt` 验证集最优,`last.pt` 最近)。

## 采样

```bash
# CPU 即可采样
python sample.py --ckpt ckpt/best.pt --n 1000 --temperature 1.0 --top-k 50

# 贪心解码
python sample.py --ckpt ckpt/best.pt --n 100 --greedy
```

结果保存到 `outputs/samples.csv`,并打印 validity / uniqueness 统计。

## 结构

- `config.py` — cpu_quick / gpu_full 两套预设
- `data.py` — 数据下载、字符级词表、按长度分批的 DataLoader
- `model.py` — 手搓 Transformer(注意力/FFN/LayerNorm 均为手写)
- `train.py` — 训练循环(warmup+cosine lr、AMP、验证 loss、续训)
- `sample.py` — 自回归采样(temperature / top-k)+ 有效性检查
